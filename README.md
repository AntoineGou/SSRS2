# SSRS2
SSRS2 — Cross-platform RDLC report engine for .NET 8/9/10. Generate PDFs, Excel, Word, and images on Linux, macOS, and Windows without GDI+ or libgdiplus dependencies. Drop-in replacement for Microsoft Report Viewer with full support for tables, charts, subreports, expressions, and hyperlinks. Production-ready, lightweight, and actively maintained.
